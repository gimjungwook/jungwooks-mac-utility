# Jungwook's Mac Utility

MacBook의 노치에서 이동 모드, 팬 제어, 창 배치와 타이핑 밈을 쓰는 무료 macOS 앱입니다.

**[v0.26 미리보기 다운로드](https://github.com/gimjungwook/jungwooks-mac-utility/releases/tag/v0.26-preview)** · Apple Silicon · macOS 14 이상

## 설치

1. 릴리스에서 `Jungwooks-Mac-Utility-v0.26-preview-apple-silicon.dmg`를 받습니다.
2. DMG를 열고 `Jungwook's Mac Utility.app`을 Applications로 끌어 놓습니다. 기존 앱이 있다면 먼저 종료합니다.
3. 응용 프로그램 폴더에서 앱을 실행합니다. 이 미리보기는 **Apple 공증을 받지 않은 ad-hoc 서명 앱**입니다. 실행이 차단되면, 앱을 한 번 열어 본 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 선택합니다. [Apple의 실행 안내](https://support.apple.com/en-us/102445)를 확인하세요.
4. 창 배치와 입력 표시를 쓰려면 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 앱을 허용합니다. 앱을 다시 실행하면 화면 위 노치 근처에 잠깐 패널이 열립니다. 평소에는 노치 가까이 마우스를 대거나 Control+Option+P를 누릅니다.
5. 팬과 이동 모드를 쓸 때만 DMG 안의 `절전 권한 설정.command`를 실행하고 관리자 암호를 입력합니다. 자세한 설치·제거 방법은 [INSTALL.md](INSTALL.md)에 있습니다.

앱은 로그인 실행을 등록합니다. macOS가 승인을 요구하면 로그인 항목 설정에서 허용합니다. 첫 실행에서는 이동 모드를 직접 켭니다.

## 기능

- **아일랜드 패널:** 평소에는 베젤에 붙어 있다가 마우스를 가까이 대면 펼쳐집니다.
- **팬:** 자동, 4000 rpm, 최대 속도 세 가지만 고릅니다.
- **이동 모드:** 시스템 절전을 막고, 덮개를 연 동안 화면을 켜 둡니다. 덮개를 닫으면 배터리 저전력 모드를 켭니다. 외부 화면이 없으면 내장 화면 밝기를 0으로 낮추고, 열면 원래 밝기로 복원합니다. 덮개를 열고 일할 때는 저전력을 끄거나 원래 고성능 설정을 유지합니다. 핫스팟 연결 자체는 macOS 설정에 따릅니다.
- **창 배치:** Control+Option과 함께 U/I/O는 왼쪽·가운데·오른쪽 1/3, J/L/K는 왼쪽·오른쪽·가운데 절반입니다. Rectangle과 키가 겹치면 한쪽 단축키를 꺼야 합니다.
- **입력 표시:** 단어, 연속, 입력창 모드와 이모지, 의미 기반 밈, 키마다 두 프레임을 번갈아 보여 주는 타이핑 밈을 지원합니다. 5초간 입력 변화가 없으면 접힙니다. 밈 위치는 왼쪽·오른쪽·자동으로 고릅니다.

설치판에는 기존 밈 GIF **1,072개**와 로컬 검색 색인이 들어 있습니다. 실행 중 GIF를 다운로드하거나 입력 내용을 서버로 보내지 않습니다.

## 미리보기의 제한

실기 확인은 **MacBook Pro M1 Max 한 대**에서 진행했습니다. 다른 Mac에서의 설치, 팬 제어, 한글 입력과 덮개 동작은 검증하지 않았습니다. Apple의 비공개 하드웨어 API를 쓰는 일부 기능은 macOS 업데이트로 작동하지 않을 수 있습니다.

이동 모드는 배터리 15% 이하 또는 높은 발열에서 자동으로 꺼집니다. 밀폐된 가방 안에서 장시간 실행하는 용도로 검증하지 않았습니다. 강제 종료나 충돌 뒤에는 잠들기 방지 설정이 남을 수 있습니다. macOS의 수동 잠금, 조직 정책이나 모든 잠금 상황을 해제한다고 보장하지 않습니다.

## 입력 표시와 개인정보

단어·연속 모드는 현재 입력창의 편집 가능 여부를 확인합니다. 입력창 모드는 현재 포커스된 입력값을 읽습니다. 키 이벤트와 입력창을 변경하지 않으며 클립보드는 읽지 않습니다. 비밀번호와 macOS 보안 입력은 제외합니다. 입력 내용을 파일·로그·설정·네트워크로 저장하거나 보내지 않습니다. 앱 전환과 보안 입력에서 표시 내용을 비웁니다.

## 소스 빌드

Xcode Command Line Tools와 Swift 5.9 이상이 필요합니다. 소스 저장소에는 코드와 출처·태그 목록을 넣었습니다. 큰 GIF 파일과 생성된 색인은 릴리스 설치판에만 들어 있습니다.

이미지 없이도 컴파일할 수 있지만 이미지 밈은 표시되지 않습니다. 설치판과 같은 구성을 빌드하려면 DMG의 앱 안 `Contents/Resources/Memes/` 폴더를 `Sources/MacUtility/Memes/`에 복사합니다. 직접 준비한 사용 권한이 있는 이미지로 교체해도 됩니다.

```sh
sh build.sh
```

이 명령은 빌드한 뒤 실행 중인 앱을 종료하고 `/Applications/Jungwook's Mac Utility.app`을 교체합니다. 일반 컴파일만 확인하려면 `swift build -c release`를 사용합니다.

팬 도우미가 빌드된 뒤 전원·팬 명령을 허용하려면 아래를 실행합니다.

```sh
sudo sh setup-sudoers.sh
```

이미지와 `meme-catalog.json`을 바꾼 경우 색인을 다시 생성합니다. 갤러리에 맞춘 두 프레임 번호와 자체검사도 새 이미지에 맞춰 조정해야 합니다.

```sh
swiftc -O Sources/MacUtility/MemeIndex.swift scripts/build-meme-index.swift -o /tmp/macutility-build-meme-index
/tmp/macutility-build-meme-index .
```

전체 `--selftest`에는 기존 갤러리 리소스 검사도 포함되어 있어 이미지가 없는 소스 체크아웃에서는 전체 통과하지 않습니다. v0.26 공개 설치판은 읽기 전용 자체검사 2,860개를 통과했습니다. 실제 한글 입력이나 덮개·팬의 다른 기기 호환성을 이 검사로 입증하지는 않습니다.
